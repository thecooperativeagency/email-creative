How to use this
Do not dump everything into Dealer Instructions. That box stays short: identity, tone, differentiators, hard guardrails — with blank lines between topics (Vin guidance). FAQ detail → Instant Answers. Lead-type nuance → processes + customization. Channel/system toggles → dealer/VCA settings.
Decisions locked in the 09-08 consult
  • EBR on (SMS / Established Business Relationship) for all three stores — natural first text on inquiry leads, not the awkward opt-in opener. Store-side toggle (Vin cannot flip for us).
  • Allow VCA to set appointments — same as Podium; assigns to salesperson on the lead.
  • “Disengage VCA when a human contacts the customer” = OFF — if it disengages it never re-engages; we want VCA as fail-safe when a rep lapses.
  • After-hours VCA disabled for now across stores so Podium + VCA don’t double-message. Re-enable after Podium go-dark (Sep 21).
  • AI profile names must match outbound email identity (e.g. Chloe @ Audi Baton Rouge — last name can be the store name).
  • Insights VCA dashboard — favorite for managers; do not grant full CRM dashboard access to sales reps (they see everyone’s customers).
  • Acquisition module (coming) maps cleanly to Audi KBB ICO buy/trade leads.
